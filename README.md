## 📖 如何在 GitHub 上找到並打開這個網站？

如果您目前在 GitHub 倉庫頁面（[https://github.com/Ann1130520/sugar-sparkle](https://github.com/Ann1130520/sugar-sparkle)），有以下 **3 種最簡單的開啟方式**：

### 方式 1：從右上角「About」直接點擊（最推薦 ⭐）
1. 打開本倉庫的首頁 [https://github.com/Ann1130520/sugar-sparkle](https://github.com/Ann1130520/sugar-sparkle)。
2. 看向頁面的**最右上角**，會看到一個 **「About」** 區塊。
3. 裡面有一個藍色帶有 🌐 地球圖示的網址：  
   👉 **`https://ann1130520.github.io/sugar-sparkle/`**
4. 直接點擊它，就會在新分頁開啟網站！

---

### 方式 2：從右側欄位「Environments」點擊
1. 在本倉庫首頁的右側側邊欄往下看，會看到 **「Environments」** 區塊。
2. 裡面會標示 **`github-pages`**（並帶有 Active 綠燈標記）。
3. 點擊 `github-pages` 或其下方的 **「View deployment」** 按鈕，就能直接進入網站！

---

### 方式 3：從倉庫的「Settings」設定頁面查看
1. 在倉庫頂部選單列（Code / Issues / Pull requests...）點擊最右邊的 **⚙️ Settings**。
2. 在左側選單的「Code and automation」中點擊 **Pages**。
3. 最上方會顯示醒目的綠色區塊：  
   `Your site is live at https://ann1130520.github.io/sugar-sparkle/`
4. 點擊 **「Visit site」** 按鈕即可開啟！
